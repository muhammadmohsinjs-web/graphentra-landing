# Graphentra landing page

Keep these files in one folder:

- `index.html`
- `styles.css`
- `app.js`
- `mark.svg`

Open `index.html` in a browser. The page works as a static site with no build step. Internet access is used only to load the selected Google Fonts; standard fallback fonts are already defined.

For development, you can also open the folder with VS Code Live Server or serve it with any static web server.
